MCP Server
==========

The MCP server that used to ship with dwclib (the ``mcp`` extra and the
``dwclib-mcp`` command) has moved to
`temple_mcp <https://github.com/larib-data/temple_mcp>`_.

temple_mcp serves DWC monitoring data together with ICCA anesthesia charting
data, with pseudonymized outputs. Its ``dwc_*`` tools replace the former
``dwclib_*`` tools. See the temple_mcp documentation for installation and
client configuration.
